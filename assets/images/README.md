# Imágenes de la portada

Guarda las imágenes descargadas en esta carpeta con estos nombres. La página las cargará automáticamente; mientras falte un archivo, se muestra un espacio con el nombre esperado.

- `banner-principal.webp` — banner grande del inicio.
- `banner-whatsapp-pila.webp` — franja promocional de PILA por WhatsApp.
- `video-alianza.webp`, `video-udea.webp`, `video-grupo-exito.webp` — miniaturas de historias en video.
- `juan-tettay.webp`, `jose-salazar.webp`, `melissa-gomez.webp` — fotos de testimonios.
- `fondo-pymes.webp` — fondo de la sección para Pymes.
- `fondo-empresas.webp` — fondo de la sección para Empresas.
- `blog-pila.webp`, `blog-seguridad-social.webp` — imágenes de artículos del blog.
- `fondo-registro.webp` — fondo de la franja de registro antes del pie.
